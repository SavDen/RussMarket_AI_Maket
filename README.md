# Руссмаркет — AI-сводка

Интерактивный ответ на тестовое задание: инструкции для AI, ручной разбор четырёх исходных случаев, план первого запуска и коммерческая концепция развития.

Демо использует подготовленные данные. Реальные CRM, чаты и модели не подключены. Мастер подключения ботов в коммерческой части показывает будущий сценарий продукта.

## Сайт

GitHub Pages: https://savden.github.io/RussMarket_AI_Maket/

После push в `main` workflow **Publish GitHub Pages** проверяет JavaScript, собирает автономный HTML и публикует папку `_site`. Состояние публикации видно во вкладке **Actions**. Для Pages выбран источник **GitHub Actions**.

## Где править

Основная рабочая папка: `/Users/DenS/Git/RussMarket_AI_Maket`.

- `demo/index.html` — разметка обеих презентаций.
- `demo/app.js` — интерактивность, данные четырёх случаев и коммерческие сценарии.
- `demo/answer-text.js` — текст ответа для отправки.
- `demo/*.css` — оформление; `inverted.css` — последняя синяя палитра и мастер подключения.
- `demo/assets/` — изображения, шрифты, официальные иконки и лицензии.
- `Руссмаркет — AI-сводка.html` — автономная копия для открытия без интернета.
- `Ответ на тестовое — Руссмаркет.txt` — отдельный ответ по заданию.

Правим исходники в `demo/`. Готовый автономный HTML пересобирается; вручную его не редактируем.

## Сборка и обновление

Нужны Python 3 и Node.js. Сторонние пакеты не требуются.

```sh
node --check demo/app.js
node --check demo/answer-text.js
node demo/export-answer.cjs
python3 demo/build_standalone.py
```

Для проверки результата сборки Pages:

```sh
python3 demo/build_standalone.py --output _site/index.html
python3 -m http.server 8934 --bind 127.0.0.1 --directory _site
```

После проверки — commit и push в `main`. GitHub Actions сам обновит сайт. Копировать проект в старую папку `Testovoe` не требуется.

Рабочие снимки, временные файлы и ZIP сохраняются локально и исключены через `.gitignore`.
